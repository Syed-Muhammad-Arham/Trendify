# 🛒 Trendify - Dynamic E-Commerce Store

A responsive, high-performance e-commerce product gallery built with React. NexaCart dynamically fetches product data from a REST API and features a lightning-fast real-time search filter and an interactive product details modal for a premium user experience.

## ✨ VIP Features

- **Dynamic Data Fetching:** Automatically retrieves high-quality product listings from the DummyJSON API.
- **Real-Time Search Engine:** Instantly filter products by title, category, or tags without ever reloading the page.
- **Interactive UI:** Clean, modern product cards displaying images, titles, and floating price tags.
- **Detailed Product Modal:** Clicking on any product opens a beautifully designed popup overlay with full descriptions and a "Buy Now" CTA.
- **Fully Responsive:** Optimized layout using modern Flexbox techniques.

## 🛠️ Tech Stack

- **Frontend:** React.js (Hooks: `useState`, `useEffect`)
- **API Client:** Axios
- **Styling:** Modern Inline CSS / Flexbox

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone [https://github.com/Syed-Muhammad-Arham/Trendify.git](https://github.com/Syed-Muhammad-Arham/Trendify.git)
   ```
2. Navigate to the project directory:
   cd trend
3. Install the required dependencies:
   npm install
4. Start the development server:
   npm start
